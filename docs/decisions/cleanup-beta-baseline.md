# 保守 Clean Beta 基线

模型：官方 YAMNet，0.975 秒 16kHz mono 输入。使用原始 stereo 的声道功率作为近场候选线索，不把 Speech 类别等同“附近讲话”。仅 Speech≥0.98、歌声/说唱/哼唱最高≤0.05、Music<0.4、声道功率比例≥4 的同侧两个连续窗口允许处理；单声道与低置信原音保持。

处理：高置信候选的较强声道最多降低15%，100ms crossfade；另一声道保持逐样本相同，禁止全量 vocals 分离。只输出派生文件，Original 只读。它是非常轻的局部抑制，不能承诺去除讲话，也不能保证任何夜店场景都有改善。20 份受控主唱/讲话混合样本+主唱保护数值检查决定 Beta，未来真实场所样本扩大需要新基线。

YAMNet 的 Singing 分数可能偏低，因此额外使用 Music 否决，并要求高讲话优势与稳定声道线索；仍可能误判，默认保留可随时回听的 Original。
